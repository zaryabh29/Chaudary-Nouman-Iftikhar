# Ch. Nouman Iftikhar — Professional Portfolio

A premium, dark-themed personal portfolio website for **Ch. Nouman Iftikhar** (Chairman & CEO of MGC Developments, and the second-generation steward of the Mian Group of Chakwal). 

This project is a static, highly-optimised HTML, CSS, and vanilla JavaScript website designed to serve as a production-quality marketing and executive presence site.

## Features
- **Dark Luxury Aesthetics:** Deep charcoal and navy backgrounds with elegant antique gold accents.
- **Scroll-Linked Animations:** Elements reveal dynamically as you scroll down the page.
- **Performance Optimized:** No heavy JS frameworks. Lightweight vanilla JavaScript for DOM manipulation and intersection observers.
- **Responsive Design:** Fully responsive layout that looks great on mobile phones, tablets, and large desktop screens.
- **Interactive UI:** Custom glowing cursor (on desktop), magnetic button hover effects, and a 3D tilt effect on project cards.
- **Timeline & Milestones:** A dynamic visual timeline tracking the history and growth of the Mian Group of Chakwal.

## Technologies Used
- **HTML5:** Semantic and accessible structure.
- **CSS3:** Custom variables, CSS Grid/Flexbox, and smooth transition effects.
- **Vanilla JavaScript (ES6):** Used for the typewriter effect, smooth scrolling, intersection observers, and interactive hover states.

## Project Structure

## Deployment
This project is completely static and requires no build step or package manager.

### Vercel Deployment (Recommended)
You can easily deploy this repository using [Vercel](https://vercel.com/):
1. Push this code to a new repository on your GitHub account.
2. Go to your Vercel Dashboard and click **Add New... > Project**.
3. Import your newly created GitHub repository.
4. Leave the Framework Preset as **Other** and click **Deploy**.
5. Your portfolio will be live globally in seconds!
